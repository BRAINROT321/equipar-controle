# Equipar

Sistema web simples para cadastrar equipamentos e controlar empréstimos e devoluções.

## Como usar

Abra `index.html` em um navegador moderno. Não é necessário instalar dependências ou iniciar um servidor.

## Recursos

- Cadastro, edição, busca e filtros de equipamentos.
- Controle de disponibilidade, condição e manutenção.
- Registro de empréstimos com responsável e data prevista de devolução.
- Registro de devoluções com atualização do estado do equipamento.
- Histórico, indicadores do acervo e identificação de empréstimos atrasados.
- Interface adaptável a computadores e celulares.

## Armazenamento

Os registros são salvos no armazenamento local do navegador (`localStorage`) e ficam disponíveis somente naquele navegador e dispositivo. Esta versão não possui servidor, autenticação ou sincronização entre usuários. Limpar os dados do navegador pode apagar os registros.
